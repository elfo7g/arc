# Nilo Model Slot

Place future Nilo model assets here.

Recommended first target:

- `nilo.glb` for a lightweight 3D model
- 1 idle animation
- 1 talking animation
- transparent or dark-friendly materials

The app currently renders Nilo through `NiloHomeStage` in `App.js`.
When the model is ready, replace the `Image` in that component with the model renderer.
